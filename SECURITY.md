# Security Policy

## Supported Versions

Atualmente, apenas a versão mais recente do Compass recebe suporte e atualizações de segurança.

| Version | Supported |
| ------- | ---------- |
| Latest  | ✅ |

---

## Reporting a Vulnerability

Se você encontrar alguma vulnerabilidade de segurança, comportamento inesperado ou possível falha no sistema, entre em contato de forma responsável antes de divulgar publicamente.

Por favor, envie um relatório contendo:
- descrição da vulnerabilidade;
- passos para reproduzir;
- possível impacto;
- capturas de tela ou logs (se necessário).

Contato:
- GitHub Issues
- Email: carlossantos.gp54@gmail.com

## Security Notes

O projeto Compass não armazena informações sensíveis reais e foi desenvolvido com foco educacional durante o Grand Prix SENAI.

Mesmo assim, algumas práticas de segurança foram adotadas:
- utilização de variáveis de ambiente para informações sensíveis;
- exclusão de arquivos `.env` do repositório;
- atualização periódica de dependências;
- verificação de vulnerabilidades utilizando `npm audit`.

---

## Responsible Disclosure

Pedimos que vulnerabilidades sejam reportadas de forma privada e responsável, permitindo tempo adequado para análise e correção antes de qualquer divulgação pública.
