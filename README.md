## ◈ Visão Geral

O **Compass** é um sistema de gestão logística portuária desenvolvido durante o **Grand Prix SENAI 2026**, em resposta ao desafio proposto pela **Vale**.

A plataforma centraliza e automatiza operações críticas de ambientes portuários, substituindo processos manuais por uma interface operacional unificada — desde o rastreamento de frotas até a geração de relatórios em tempo real.

---

## ✦ Funcionalidades

| ◆ Módulo | › Descrição |
|----------|-------------|
| `[ Dashboard Operacional ]` | Visão centralizada de todas as operações em tempo real |
| `[ Gestão de Frota ]` | Cadastro e monitoramento de veículos e operadores |
| `[ Roteamento Automático ]` | Cálculo e otimização de rotas portuárias |
| `[ Mapa Logístico ]` | Visualização geoespacial interativa via Leaflet |
| `[ Controle de Estoque ]` | Rastreamento e gestão de cargas |
| `[ Pontos Interditados ]` | Monitoramento e gestão de bloqueios operacionais |
| `[ Relatórios ]` | Geração de relatórios de rotas e operações |

## ▸ Como Executar Localmente

**Pré-requisitos:** Node.js `v18+` e npm instalados.

```bash
# › Clone o repositório
git clone https://github.com/carloshenrique54/Compass.git

# › Acesse o diretório
cd Compass

# › Instale as dependências
npm install

# › Inicie o servidor de desenvolvimento
npm run dev
```

O projeto estará disponível em `http://localhost:5173`

## ★ Contexto — Grand Prix SENAI 2026

O **Grand Prix SENAI** é uma competição técnica nacional onde equipes de estudantes desenvolvem soluções reais para desafios propostos por grandes empresas.

O desafio da **Vale** exigia uma solução que otimizasse a logística operacional portuária — o Compass foi a resposta da equipe, conquistando o **3º lugar nacional** entre dezenas de projetos concorrentes.
